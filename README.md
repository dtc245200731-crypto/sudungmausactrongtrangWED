Bài tập: Phối màu cho newsletter
Dự án này thực hành lựa chọn bộ màu sắc bằng **Adobe Color** và áp dụng biến CSS (CSS Variables) vào khung **Bootstrap 5** để tạo ra hai phiên bản Newsletter có phong cách thị giác hoàn toàn khác nhau.
Danh sách các phiên bản:
1. Phiên bản 1 
   - Chủ đề màu: Modern Blue (Xanh công nghệ & Hiện đại).
   - Mã màu HEX:
     - Primary: `#0079BF`
     - Secondary: `#026AA7`
     - Accent: `#00C2E0`

2. Phiên bản 2 
   - Chủ đề màu: Warm Sunset (Cam năng lượng & Tím sáng tạo).
   - Mã màu HEX:
     - Primary: `#FF5630`
     - Secondary: `#6B5B95`
     - Accent: `#FFAB00`
  
Công nghệ sử dụng:
- HTML5 & CSS3 (Custom Properties / Variables)
- Framework CSS: Bootstrap 5.3.3
- Công cụ phối màu: Adobe Color
